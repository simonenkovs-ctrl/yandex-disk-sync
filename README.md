# ☁️ Яндекс Диск Синхронизатор для Windows

Полноценное десктопное приложение для двусторонней синхронизации файлов между ПК и Яндекс Диском (с поддержкой фонового режима, системного трея и разрешения конфликтов).

---

## 🚀 Возможности

1. **Двусторонняя синхронизация (ПК ↔ Яндекс Диск)**:
   - Загрузка новых и измененных файлов с ПК в облако.
   - Скачивание файлов, добавленных или измененных в облаке (через браузер или телефон), на ПК.
   - Синхронизация удаления файлов (опционально, можно выключить в настройках).
   - Интеллектуальное кэширование хешей MD5 (не пересчитывает большие неизмененные файлы заново).

2. **Защита от конфликтов и потери данных**:
   - Автоматическое определение ситуаций, когда файл был изменен одновременно на ПК и в облаке.
   - Стратегия по умолчанию: **Сохранять оба файла** (локальный файл переименовывается с добавлением временной метки `_Конфликт_PC_...`, скачивается облачная версия и загружается локальная копия). Ни один байт не теряется!

3. **Интерфейс и системный трей**:
   - Наглядный индикатор статуса соединения (🟢 Подключено / 🔴 Ошибка).
   - Графический индикатор занятого и свободного места на Яндекс Диске.
   - Детальный журнал операций с подсветкой цветом (загрузка, скачивание, удаление, конфликты).
   - Работа в системном трее Windows: при закрытии крестиком окно сворачивается в область уведомлений около часов.
   - Контекстное меню в трее: открытие окна, быстрая синхронизация, пауза, выход.

4. **Автономность**:
   - Работает на встроенных библиотеках Python (без обязательной установки громоздких внешних пакетов).
   - Быстрый запуск в один клик через `.bat`.

## 📋 Как запустить

### Вариант 1 (Самый простой):
Дважды кликните по файлу:
```
run_yandex_disk.bat
```
*(находится в корне папки или в папке `yandex_disk_sync\run.bat`)*

### Вариант 2 (Через командную строку):
```cmd
cd yandex_disk_sync
python main.py
```

## 🔑 Как получить OAuth-токен Яндекс Диска (за 30 секунд)

### Способ 1: Официальный Полигон Яндекс.Диска (Рекомендуется)
1. Откройте в браузере: **[Полигон Яндекс.Диска](https://yandex.ru/dev/disk/poligon/)**
2. Войдите в свой Яндекс-аккаунт.
3. В правом верхнем углу страницы нажмите желтую кнопку **«Получить OAuth-токен»**.
4. Скопируйте полученную строку (вида `y0_AgAAAA...`).
5. В приложении во вкладке **«Настройки»** вставьте её в поле **«OAuth-токен доступа»** и нажмите **«Сохранить»**.

### Способ 2: Создание собственного приложения на oauth.yandex.ru
1. Перейдите на https://oauth.yandex.ru/client/new
2. Название: `MyDiskSync`
3. Платформа: «Веб-сервисы» → Redirect URI: `https://oauth.yandex.ru/verification_code`
4. Права доступа (REST API Диска):
   - `Доступ к информации о Диске` (`cloud_api:disk.info`)
   - `Доступ к папке приложения на Диске` или `Чтение и запись всех файлов на Диске` (`cloud_api:disk.read`, `cloud_api:disk.write`)
5. Сохраните приложение, скопируйте `ID` и перейдите по ссылке:
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ВАШ_ID>`
6. Предоставьте доступ и скопируйте токен.

## ⚙️ Настройки приложения

- **Локальная папка на ПК**: папка, файлы из которой синхронизируются (по умолчанию `C:\Users\<Имя>\YandexDiskSync`).
- **Папка на Яндекс Диске**: целевая папка в облаке (по умолчанию `/SyncFolder`). Если папка еще не создана, приложение создаст её автоматически.
- **Интервал автосинхронизации**: как часто программа проверяет изменения (от 5 до 3600 секунд, по умолчанию 30 сек).
- **Разрешение конфликтов**:
  - `Сохранять оба файла` (рекомендуется)
  - `Брать более свежий файл`
  - `Приоритет ПК`
  - `Приоритет Облака`
- **Синхронизация удалений**: если файл удален на одной стороне, удалять ли его на второй стороне.

## 📦 Кэш‑манифест и локальный кеш удалённых файлов

Начиная с версии 1.2 в приложении реализован механизм **кэш‑манифеста**:

1. **`.sync_manifest.json`** – файл, сохраняемый в корне удалённой папки (`/SyncFolder`). Он содержит список всех файлов в облаке со свойствами `md5`, `size` и `modified`.
2. **Локальный кеш** – SQLite‑таблица `remote_cache` (файл `sync_state.db`). При старте приложение пытается загрузить манифест, заполняет эту таблицу и дальше использует её вместо полного `list_folder_recursive`‑запроса к API.
3. **Обновление манифеста** происходит только тогда, когда в ходе синхронизации произошли изменения (загрузка, скачивание, удаление). Это существенно экономит трафик и ускоряет запуск.

### Как это работает
- При первом запуске манифест не найден, приложение делает обычный запрос к API, сохраняет полученный список в `remote_cache` и создаёт `.sync_manifest.json` в облаке.
- При последующих запусках приложение читает манифест, сразу заполняет `remote_cache` и использует его для сравнения с локальными файлами.
- После завершения синхронизации, если был изменён хотя бы один файл, манифест перезаписывается и кеш обновляется.

### Что изменить в конфигурации
Никаких дополнительных настроек не требуется. По умолчанию включён режим `sync_deletions = true` и `conflict_resolution = keep_both`. При желании можно выключить манифест, удалив файл `.sync_manifest.json` из облака – приложение вернётся к прежнему поведению.
