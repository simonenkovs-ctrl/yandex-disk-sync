## 1. Общее описание и назначение

**Яндекс Диск Синхронизатор для Android** — мобильный клиент для двусторонней синхронизации и резервного копирования файлов смартфона в облачное хранилище Яндекс Диск. 

Приложение спроектировано с учетом современных требований Android Scoped Storage и не зависит от закрытых проприетарных сервисов Google Mobile Services (GMS), что позволяет запускать его на любых Android-устройствах (включая HUAWEI, Xiaomi, Pixel, Samsung и AOSP-прошивки).

## 2. Ключевые отличия от десктопной версии

| Параметр | Десктопная версия (PC) | Мобильная версия (Android) |
|---|---|---|
| **Количество папок** | 1 фиксированная пара | **Неограниченное количество пар** папок |
| **Выбор локальных путей** | Локальные диски Windows (`C:\...`) | Системный проводник **SAF (`DocumentFile`)** с постоянными правами доступа |
| **Режимы для каждой папки** | Общий для программы | **Индивидуальный** (`Двусторонняя`, `Только бэкап в облако`, `Только скачивание`) |
| **Запуск синхронизации** | Таймер + трей | **Ручной запуск в 1 клик** + независимый одиночный запуск для каждой папки |
| **Сон и блокировка** | Работа в системном трее | **Foreground Service** + `PARTIAL_WAKE_LOCK` + `WIFI_MODE_FULL_HIGH_PERF` |
| **Обновления** | Скачивание установщика вручную | **Встроенный автоапдейтер** прямо из приложения |

### 3.1. Клиент REST API Яндекс Диска (`api/`)

Файл: `YandexDiskClient.kt`
- Базовый URL: `https://cloud-api.yandex.net/v1/disk`
- Аутентификация: заголовок `Authorization: OAuth <токен>`.
- Обработка сбоев: встроенный механизм экспоненциального отката (exponential backoff) и учет заголовка `Retry-After` при HTTP 429 (Too Many Requests) и 5xx (ошибки сервера).
- Методы:
  - `getDiskInfo()` — получение квоты (занято/всего байт) и данных профиля.
  - `listFolderRecursive(path)` — итеративный постраничный обход облачного дерева с лимитом `limit=100`.
  - `createFolder(path)` — создание каталогов с автоматическим созданием всех промежуточных родительских папок.
  - `uploadFile(...)` — потоковая загрузка файла с вычислением прогресса на лету через `BufferedSink`.
  - `downloadFile(...)` — потоковое скачивание файла в `OutputStream` документа.
  - `deleteResource(path)` — удаление файла или папки в облаке.

### 3.2. Слой данных и хранилище (`data/`)

1. **`SyncFolderPair`**:
   - `id`: уникальный идентификатор (UUID).
   - `displayName`: пользовательское название (например, «Фотографии»).
   - `localTreeUri`: устойчивый Android URI каталога (`content://...`).
   - `localReadablePath`: декодированный понятный путь (например, `Основная память: /DCIM/Camera`).
   - `remotePath`: путь в Яндекс Диске (например, `/PhoneSync/Фото`).
   - `mode`: режим работы (`TWO_WAY`, `UPLOAD_ONLY`, `DOWNLOAD_ONLY`).
   - `enabled`: флаг активности.
   - `lastSyncTime`, `lastSyncStatus`, `lastSyncFilesCount`.

2. **База данных Room SQLite (`AppDatabase`)**:
   - Таблица `file_records` хранит слепки файлов:
     `id` (`pairId:relPath`), `localMd5`, `remoteMd5`, `localMtime`, `remoteMtime`, `size`, `lastSyncTime`.
   - Исключает повторное скачивание и загрузку файлов, если их содержимое не менялось.

3. **`AppPreferences`**:
   - Потокобезопасное хранение токена, настроек и списка папок с реактивным обновлением UI через Kotlin `StateFlow`.

---

### 3.3. Движок синхронизации (`engine/`)

Файл: `SyncEngine.kt`
- **Хеширование:** вычисление MD5 через потоковый `MessageDigest` блоками по 64 КБ без загрузки файла целиком в оперативную память.
- **Фильтрация мусора:** автоматический пропуск временных и системных файлов (`.nomedia`, `desktop.ini`, `thumbs.db`, `.tmp`, `.crdownload`, `.part`, `.bak` и др.).
- **Режимы синхронизации:**
  - `UPLOAD_ONLY` (Резервная копия): проверяет наличие файла в облаке и соответствие MD5. Загружает новые и измененные файлы. Локальные файлы на телефоне **никогда не удаляются и не перезаписываются**.
  - `DOWNLOAD_ONLY`: скачивает новые/измененные файлы из облака на телефон.
  - `TWO_WAY` (Двусторонняя): синхронизирует изменения в обе стороны. При включенной опции `syncDeletions` удаляет файл, если он был удален на противоположной стороне.

---

### 3.4. Фоновая служба и удержание процессора (`service/`)

Файл: `SyncForegroundService.kt`
Приложение гарантирует выполнение синхронизации при заблокированном экране и при сворачивании благодаря трем механизмам:
1. **Foreground Service** с типом `dataSync` и постоянным уведомлением в системной шторке.
2. **`PowerManager.WakeLock` (`PARTIAL_WAKE_LOCK`)**: удерживает процессор в активном состоянии, не давая операционной системе усыпить CPU при выключении дисплея.
3. **`WifiManager.WifiLock` (`WIFI_MODE_FULL_HIGH_PERF`)**: предотвращает переход модуля Wi-Fi в режим энергосбережения с обрывом сокетов.

---

### 3.5. Встроенный модуль автообновления (`updater/`)

Файлы: `AppUpdater.kt`, `UpdateDialog.kt`, `file_paths.xml`
- Обращается к публичному API GitHub Releases (`/repos/simonenkovs-ctrl/yandex-disk-sync/releases`).
- Находит релизы с тегом `*android*` и проверяет номер версии.
- Скачивает APK в изолированный кэш приложения (`context.cacheDir/updates/`).
- Формирует безопасный URI через **AndroidX FileProvider** (`content://ru.simonenkov.yandexdisksync.fileprovider/...`).
- Вызывает стандартный системный установщик Android (`Intent.ACTION_VIEW` с MIME `application/vnd.android.package-archive`).

### 3.6. Пользовательский интерфейс (`ui/`)

- Реализован на **Jetpack Compose** в концепции декларативного UI.
- Навигационная панель (Bottom Navigation) с 4 экранами:
  1. **Главная (`MainScreen`)**:
     - Карточка Яндекс Диска: отображение логина, прогресс-бар квоты (занято / свободно в ГБ).
     - Кнопка **«СИНХРОНИЗИРОВАТЬ СЕЙЧАС»** с отображением текущего файла, процентов и кнопкой «Остановить».
     - Список синхронизируемых папок с быстрыми переключателями и кнопкой одиночного запуска.
  2. **Папки (`FoldersScreen`)**:
     - Добавление каталогов через кнопку `+`.
     - Настройка режимов и удаление.
  3. **Журнал (`LogScreen`)**:
     - Черный терминальный лог в реальном времени с временными метками и цветовой подсветкой (зеленый — успех, оранжевый — предупреждение, красный — ошибка).
  4. **Настройки (`SettingsScreen`)**:
     - Ввод и проверка OAuth-токена.
     - Индикатор оптимизации батареи с кнопкой перехода в системные настройки.
     - Переключатели: «Синхронизация только по Wi-Fi», «Синхронизировать удаление файлов».

## 4. Разрешения Android (Permissions) и безопасность

В `AndroidManifest.xml` запрошены только необходимые разрешения:

| Разрешение | Зачем требуется |
|---|---|
| `INTERNET` | Доступ к облачному REST API Яндекс Диска и GitHub API |
| `ACCESS_NETWORK_STATE` | Определение наличия активного подключения к сети |
| `ACCESS_WIFI_STATE` | Проверка Wi-Fi соединения для опции «Только по Wi-Fi» |
| `WAKE_LOCK` | Предотвращение засыпания процессора при выключении дисплея |
| `FOREGROUND_SERVICE` | Запуск фоновой службы синхронизации |
| `FOREGROUND_SERVICE_DATA_SYNC` | Требование Android 14+ для служб синхронизации данных |
| `POST_NOTIFICATIONS` | Показ уведомления о прогрессе в шторке Android 13+ |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Запрос на отключение режима глубокого сна (Doze mode) |
| `REQUEST_INSTALL_PACKAGES` | Установка обновлений APK прямо из приложения |

## 5. Руководство пользователя

### 5.1. Первый запуск и авторизация
1. Установите и откройте приложение.
2. При первом запуске разрешите показ уведомлений (для отображения статуса в шторке).
3. Перейдите во вкладку **«Настройки»**:
   - Нажмите **«Получить токен»** (откроется [Полигон Яндекс Диска](https://yandex.ru/dev/disk/poligon/)).
   - Нажмите на сайте желтую кнопку **«Получить OAuth-токен»** и скопируйте его.
   - Вставьте токен в поле ввода и нажмите **«Проверить токен»**. Появится зеленая надпись с вашим именем пользователя.

### 5.2. Добавление и настройка папок
1. Откройте вкладку **«Папки»** и нажмите кнопку **«+»**.
2. Нажмите на блок **«Локальная папка на телефоне»**:
   - Откроется стандартный проводник файлов Android.
   - Выберите любую нужную папку (например, `DCIM` -> `Camera`, `Download` или `Documents`).
   - Нажмите внизу экрана **«Использовать эту папку»** и подтвердите доступ.
3. Укажите целевой путь на Яндекс Диске (например, `/PhoneSync/Фото`). Если такой папки в облаке нет, приложение создаст её автоматически.
4. Выберите подходящий режим:
   - **Только бэкап в облако** — идеально для фото и видео (оригиналы на телефоне в полной безопасности).
   - **Двусторонняя** — для рабочих документов.
5. Нажмите **«Сохранить»**.

### 5.3. Ручной запуск и отслеживание прогресса
- Для синхронизации всех активных папок: на вкладке **«Главная»** нажмите большую красную кнопку **«СИНХРОНИЗИРОВАТЬ СЕЙЧАС»**.
- Для синхронизации конкретной папки: нажмите круглую стрелку 🔄 в карточке этой папки.
- Текущий прогресс и лог можно отслеживать на вкладке **«Журнал»**.

### 5.4. Настройка непрерывной работы при блокировке
Чтобы телефон не прерывал передачу больших объемов фото при выключении экрана:
1. Зайдите во вкладку **«Настройки»**.
2. В карточке **«Работа в фоновом режиме и блокировка»** нажмите **«Разрешить работу без ограничений»**.
3. Подтвердите отключение оптимизации батареи в появившемся системном окне Android.

### 5.5. Обновление приложения в 1 клик
- В правом верхнем углу приложения нажмите на значок облака со стрелкой ☁️.
- При наличии свежей версии появится окно со списком изменений.
- Нажмите **«Скачать и установить»** — приложение скачает обновление и запустит установщик.

## 6. Руководство разработчика и сборка

### 6.1. Автоматическая сборка в GitHub Actions
Сборка полностью автоматизирована через workflow-файл [`.github/workflows/build-apk.yml`](file:///D:/yandex-disk-sync-1.2.2/.github/workflows/build-apk.yml).

- **Триггер:** любой `git push` в ветку `android` или `master`.
- **Окружение:** `ubuntu-latest`, OpenJDK 17.
- **Команда сборки:**
  ```bash
  cd android
  gradle wrapper
  ./gradlew assembleDebug --no-daemon
  ```
- **Результат:** готовый APK-файл автоматически прикрепляется к артефактам сборки в репозитории GitHub.

### 6.2. Локальная сборка в Android Studio
1. Откройте Android Studio.
2. Выберите **File ➔ Open** и укажите папку `D:\yandex-disk-sync-1.2.2\android`.
3. Дождитесь автоматической загрузки зависимостей Gradle (Sync Project with Gradle Files).
4. Выберите в верхнем меню: **Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)**.
5. Готовый файл появится в каталоге:
   `app/build/outputs/apk/debug/app-debug.apk`.
