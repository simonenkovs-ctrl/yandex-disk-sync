# 📱 Яндекс Диск Синхронизатор для Android

Нативное Android-приложение (Kotlin + Jetpack Compose) для синхронизации локальных папок смартфона с Яндекс Диском.

---

## ✨ Ключевые возможности

1. **Ручной запуск синхронизации**:
   - Кнопка **«Синхронизировать сейчас»** на главном экране.
   - Возможность запустить синхронизацию как для всех включенных папок сразу, так и для каждой выбранной папки отдельно.
   - Отображение текущего прогресса: процент, имя передаваемого файла, скорость и объем переданных байт.
   - Возможность безопасной отмены операции в любой момент.

2. **Выбор нескольких папок для синхронизации**:
   - Системный выбор любых каталогов телефона (DCIM/Фотографии, Загрузки, Документы, папки мессенджеров) через современный **Storage Access Framework (SAF)** с сохранением постоянных прав доступа.
   - Индивидуальная привязка каждой локальной папки к целевой папке на Яндекс Диске (например: `DCIM/Camera` ➔ `/PhoneSync/Фото`).
   - Настраиваемый режим для каждой папки:
     - **Двусторонняя (`TWO_WAY`)**: изменения в облаке передаются на телефон, новые файлы с телефона — в облако.
     - **Только бэкап в облако (`UPLOAD_ONLY`)**: выгружает новые фото/файлы в облако, никогда не удаляет файлы на смартфоне.
     - **Только скачивание (`DOWNLOAD_ONLY`)**: загружает файлы из облака на телефон.
   - Быстрое включение/отключение отдельных папок свитчами.

3. **Фоновый сервис (Foreground Service)**:
   - Синхронизация не прерывается при блокировке экрана или сворачивании приложения.
   - В шторке уведомлений отображается текущий статус и кнопка «Остановить».

4. **Локальная база данных (Room SQLite)**:
   - Хранение хэшей MD5 и метаданных файлов.
   - Не загружает неизмененные файлы повторно, экономя заряд батареи и трафик.

5. **Журнал операций (Log)**:
   - Подробный лог в реальном времени с цветовой подсветкой (загрузка, скачивание, ошибки, статус).

## 🛠 Как собрать APK

### Способ 1: Автоматическая облачная сборка через GitHub Actions (Рекомендуется)
В проект уже добавлен готовый workflow: `.github/workflows/build-apk.yml`.
1. Сделайте `git push` в ваш репозиторий GitHub.
2. Во вкладке **Actions** в репозитории запустится сборка `Build Android APK`.
3. Через ~1.5 минуты в блоке **Artifacts** будет готов файл `yandex-disk-sync-debug-apk.zip` с готовым APK-файлом для установки на телефон.

### Способ 2: Сборка через Android Studio
1. Откройте папку `D:\yandex-disk-sync-1.2.2\android` в Android Studio.
2. Дождитесь автоматической синхронизации Gradle.
3. В верхнем меню выберите: **Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)**.
4. Готовый APK появится в папке `app/build/outputs/apk/debug/app-debug.apk`.
